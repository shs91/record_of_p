## 결정 — 방향 B "카테고리 타일"

카드 왼쪽에 카테고리 색 타일을 두어 목록을 훑을 때 장소 종류가 먼저 보이게 한다. 바탕(흰 종이, 잉크 타이포, 블루는 행동에만)은 그대로 둔다.

- A(칩 아이콘만 색)는 변화가 작아 성격이 드러나지 않는다.
- C(홈에 "1km 안 3개"와 거리 숫자)는 앱을 열 때마다 위치를 받아 거리를 계산하는 기능이 필요하고, 위치가 오래되면 숫자가 틀린다. 블루를 장식 면에 써서 §1.2 원칙도 어긋난다. 거리 숫자 강조는 주변 보기에만 쓴다. 홈 거리 표시는 별도 기능 후보로 남긴다.

### 1.3 카테고리 색

### 1.4 간격과 모션

- `Spacing`: 4 · 8 · 12 · 16 · 20 · 24 · 32dp 단계로 정한다. 화면 좌우 여백은 20. 카드 사이 10, 칩 사이 6·8, 카드 안쪽 14·16은 컴포넌트 고유값으로 컴포넌트 안에 둔다.
- 모션: 짧은 전환 150ms(칩 선택, 버튼 눌림), 표준 250ms(카드 등장·제거, 스낵바), 이징은 Material 표준(FastOutSlowIn). 스와이프 완료 뒤 카드는 표준 시간으로 접히고 스낵바가 올라온다.

## 2. 컴포넌트

- **기록 카드**: 카드(`card`, 20dp 라운드, 안쪽 14·16) 안에 왼쪽 타일 48dp(16dp 라운드, 아이콘 24dp) + 제목(`titleMedium`) + 보조 줄(`bodySmall`, 보조 글자). 보조 줄은 트리거 이름을 " · "로 잇는다("세탁소 · 크린토피아 역삼점"). 타일은 대표 트리거 하나를 따른다: 카테고리가 있으면 첫 카테고리, 없으면 특정 지점, 없으면 브랜드. 회색 트리거 칩 줄은 없앤다.
- **개수 pill**: 홈 제목 옆, 28dp 높이, `onSurface` 바탕에 `background` 글자(15 Bold, tabular-nums). 0개면 숨긴다.
- **빈 상태**: 136dp 연블루 원 안에 P-핀 마크(블루), 둘레에 카테고리 타일 3개(편의점·약국·카페)를 조금씩 기울여 띄운다. 제목 20 Bold "아직 기록이 없어요", 본문 15 보조 글자 두 줄.
- **보호 배너**: 앰버 면(20dp 라운드, 안쪽 16) — 36dp 원(앰버 글자색 바탕, 앰버 면색 아이콘) + 제목(`titleSmall`) + 본문(`bodySmall`), 오른쪽 아래 [설정 열기] pill 버튼(40dp, 앰버 글자색 바탕, `card` 글자). 아이콘: 알림 꺼짐=종에 사선, 정확한 위치=조준점, 항상 허용=핀, 기기 위치=핀에 사선. '항상 허용'은 단계(설정 → 권한 → 위치 → 항상 허용)를 칩으로 보이고 마지막 칩만 앰버 바탕으로 강조한다.
- **완료 스와이프**: 시작→끝 한 방향. 뒤에 `success` 바탕, 왼쪽에 32dp 흰 원 체크 + "완료"(15 Bold, `onSuccess`).
- **실행 취소 스낵바**: `inverseSurface` 바탕 16dp 라운드, 56dp. 앞에 24dp 성공 체크 원(`inverseSuccess`), "완료했어요", [실행 취소](`inversePrimary`). 떠 있는 동안 FAB은 스낵바 위로 올라간다.
- **에디터**:
  - 입력 필드: `card` 바탕, 1dp `outline`, 12dp 라운드. 제목 필드는 56dp·17 SemiBold, 나머지 48~52dp·15.
  - 섹션 제목: 15 SemiBold `onSurface`("어디서 알려드릴까요?", "브랜드 추가", "특정 장소").
  - 카테고리 칩(36dp pill): 미선택 = `card` 바탕 + 1dp `outlineVariant` + 카테고리 ink 아이콘 + 잉크 글자. 선택 = 카테고리 tint 바탕 + 1.5dp 카테고리 ink 테두리 + 체크 + ink 글자(SemiBold).
  - 브랜드: 입력(입력 중 2dp 블루 테두리) + [추가](`primaryContainer` 바탕, `onPrimaryContainer` 글자) + 안내 문구(§3). 추가된 브랜드는 회색 칩(검색 아이콘 + ✕).
  - 특정 지점: 고른 지점은 연블루 칩(핀 아이콘 + ✕).
  - 저장 실패: 본문 맨 위 `errorContainer` 면(12dp 라운드) + 느낌표 원 아이콘 + 문구(`onErrorContainer`).
  - 삭제: 하단 가운데 텍스트 버튼(`error`).
- **주변 보기**: 그룹 머리 = 32dp 타일(10dp 라운드) + 카테고리 이름(`titleMedium`) + 오른쪽 "N곳"(보조 글자). 그룹마다 카드 하나에 행을 `outlineVariant` 구분선으로 나눈다. 행 64dp = 장소 이름(`titleSmall`) + "카카오맵에서 보기"(보조 글자) + 오른쪽 거리 숫자(22 Bold tabular, `onPrimaryContainer`) + 단위(13 SemiBold). 1km를 넘으면 숫자를 보조 글자색으로.
- **근처 알림**: 시스템 템플릿. 작은 아이콘은 지금의 P-핀, `setColor(primary)`로 앱 이름·아이콘에 블루를 입힌다. 여러 항목은 InboxStyle 목록과 [오늘 그만](T11 그대로).

## 4. 아이콘

목업의 카테고리 아이콘은 손으로 그린 선 아이콘이다. 구현은 Material Symbols(Rounded, Apache 2.0)에서 같은 뜻의 SVG를 VectorDrawable(`res/drawable/ic_cat_<id>.xml`)로 가져온다. 라이브러리는 추가하지 않는다.

|---|---|
| 편의점 | `storefront` |
| 대형마트 | `shopping_cart` |
| 약국 | `medication` |
| 은행 | `account_balance` |
| 우체국 | `local_post_office` |
| 주유소·충전소 | `local_gas_station` |
| 세탁소 | `checkroom` |

| 병원 | `local_hospital` |
| 지하철역 | `subway` |
| 브랜드 프리셋(다이소·올리브영) | `shopping_bag` |

카탈로그의 이모지(`TriggerCatalog.emoji`)는 화면에서 쓰지 않게 된다. 필드는 남겨 두고(iOS 포팅 때 판단) 화면 코드만 아이콘으로 바꾼다.

## 5. 보강 계획 묶음 D에 주는 영향

- **새 태스크(묶음 D 맨 앞)**: 토큰·테마 — §1.1 대비 보정, §1.2 새 토큰, §1.3 카테고리 색 헬퍼, §1.4 `Spacing`·모션 상수, §4 아이콘 drawable. `docs/design/design-system.md`를 1.2로 같은 커밋에서 바꾼다(CLAUDE.md 디자인 규칙).

- **T14 실행 취소**: §2 완료 스와이프·스낵바 모양과 FAB 위치를 반영한다.
- **새 태스크**: 홈 기록 카드·개수 pill·빈 상태, 주변 보기, 근처 알림(📍 제거·`setColor`).
- 화면마다 `@Preview` 라이트·다크 두 벌을 둔다(디자인 시스템 §5).
